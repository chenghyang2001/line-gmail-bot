# LINE 聊天記錄查找說明

> 整理日期：2026-05-21
> 問題：如何找出與 LINE 使用者 Kerwin 的對話記錄檔案

## 結論：檔案存在，但無法直接讀

## 聊天記錄檔案位置

與 Kerwin（以及所有人）的對話，全部存在這個檔案裡：

```
C:\Users\B00332\AppData\Local\LINE\Data\db\qwd351e0735f4e8b976971456623827a.edb
```

此檔約 150 MB，2026-05-21 早上 09:35 仍在更新 — 它就是 LINE 的主訊息資料庫。

## 但是：它是加密的，不能直接打開

**如何判斷一個檔案是否加密 — 看檔頭的 magic bytes：**

- 正常 SQLite 資料庫開頭是 `53 51 4C 69 74 65...`（ASCII「SQLite format 3」）
- LINE 的 `.edb` 檔開頭全是 `86 DE 28 74 1D 22 AC E8` — 這是 LINE 自訂的加密簽章
- `.edb` 的 `e` 就是 encrypted database（加密資料庫）的意思

### db 資料夾裡的檔案比對

| 檔案 | 檔頭 | 狀態 |
|------|------|------|
| `qwd351e...edb`（150MB，主訊息庫） | `86DE2874...` | 加密，讀不了 |
| `album_...edb` / `keep_...edb` / `chatStats_...edb` | `86DE2874...` | 加密 |
| `f59c00309...`（無副檔名） | `SQLite format 3` | 未加密，但只是設定快取，沒有對話內容 |

所以：對話有被記錄，但 LINE 故意把它加密，沒有現成的純文字 log 檔可以讀。
Windows 桌面版也沒有「匯出單一聊天室為文字」的功能。

## 實際可行的三個辦法（推薦順序）

### 1. 最快 — 直接在 LINE 視窗往上捲

Kerwin 的對話就在 LINE 視窗裡，往上滑就能看完整歷史，文字可以反白複製。
要「學習所有對話」其實這個最直接。

### 2. 最適合存成檔案 — 用手機版 LINE 匯出

手機 LINE → 打開 Kerwin 聊天室 → 右上選單 → 設定 → 傳送聊天記錄
→ 會產生一個 `.txt` 純文字檔，可以 email 給自己。
這是官方支援、唯一能拿到乾淨文字檔的方法。

### 3. 不建議 — 第三方 .edb 解密工具

網路上有號稱能解 LINE `.edb` 的工具，但都是非官方、常因 LINE 改版失效、
且有夾帶惡意程式的風險。雖然是自己的資料不涉及隱私問題，但實務上不建議碰。
